Séance arrêtée

Lecture, pause et stop pilotent le chronomètre et envoient la commande FTMS correspondante si le contrôle est disponible. Stop ne garantit ni un freinage physique ni une baisse de résistance. Après un arrêt, Lecture crée une nouvelle séance ; après Pause, elle reprend la séance.

Diagnostic Bluetooth et mode d’emploi

Sur ordinateur : Chrome compatible, page servie sur localhost ou HTTPS. Sur iPhone : navigateur compatible Web Bluetooth, par exemple Bluefy, à vérifier sur l’appareil. Une prévisualisation de fichier peut bloquer le Bluetooth. Fermer Kinomap et les autres applications connectées au vélo.

Cliquer sur Scanner, sélectionner le vélo dans la fenêtre du navigateur, puis Connecter. Le sélecteur système réalise le scan ; la liste de cette page conserve les appareils choisis pendant cette ouverture.

Le numéro de série n’est affiché que si le service Device Information le fournit. L’identifiant navigateur n’est ni un numéro de série ni une adresse MAC. Si le contrôle standard est refusé, exporter le diagnostic pour adapter le protocole du vélo ; aucun paquet propriétaire n’est envoyé au hasard.
